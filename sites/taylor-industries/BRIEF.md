# Build brief: Taylor Industries website redesign (static site)

You are building a modern redesign of https://www.taylor-ind.com/ (Taylor Industries Inc., Jefferson City, MO:
US contract manufacturer of ECG/EKG, TENS and Tab electrodes; also designs/builds electrode production machines
and packaging systems). It is a speculative pitch: the finished site must look like a credible, finished replacement.

## Inputs already in this folder (read them first)
- `reference/crawl-page-text.txt` - text of every page on the current site (crawled today). Image paths in it are relative to the old site; the same images are already copied into `site/assets/img/...`.
- `reference/electrode-reference-guide.txt` - text of their PDF reference guide (PDF itself is at `site/assets/Electrode_Reference_Guide.pdf`, link to it).
- `reference/old-home.html` - old home page HTML.
- `src/data.py` - product data I transcribed (ECG shapes, TENS). Use it (or port it to JS/JSON) as the single source for product grids.
- `site/assets/img/` - all real images. Notables: `brand/logo.jpg` (325x51, white bg, the real logo; keep it on a white header), `brand/electrodes-collage.webp` (900x639, transparent PNG-style cutout of their electrode range from their own brochure, made for a dark hero), product photos are 100x100 JPG on white (display at ~100-120px, never upscale beyond ~130px), machine photos are small (360px wide max). `machines/video-thumb.jpg` is the YouTube thumbnail.

## Hard content rules
- NEVER invent facts, numbers, certifications, clients, testimonials, awards or claims. Use only copy from the reference files. You may lightly trim/merge their sentences and fix obvious typos ("srips", "inovated", "electrods", "flexability").
- Keep every product, part number, size, pouch/case quantity, cloth variant (e.g. "Also available in Cloth (1000SW)") and footnote exactly as on the site. Pouch/case footnote: "*Standard pouch size of 8-1/4" x 8-1/4" with black monochromatic print. Standard shipping case 17" long x 10" wide x 9" high. Pouches shipped bulk with no inside boxes. Other pouch sizes and quantities per pouch are available."
- Items that exist only in the PDF guide (TENS 532204152 and 53101152, Grounding Pad GP96 with image `misc/gp96.jpg`, Tab part number TITAB) may be included but label the source subtly only if needed; prefer simply including them in tables.
- Their "over 17 years" (electrodes) and "over fourteen years" (machines) claims are from 2009-era copy: keep them out of headlines; it's OK to omit them entirely. Do not compute new numbers.
- Contact: Taylor Industries Inc., 2704 Industrial Drive, Jefferson City, MO 65109. Phone 573.893.5412, Fax 573.893.3647, sales@taylor-ind.com. "A Family Owned & Operated Company" (from their logo) may be used once.
- Video: YouTube id `lV67T6aLGC0` ("ECG Electrode Production Machine", channel @taylorind). Embed as click-to-load facade (thumbnail + play button, load youtube-nocookie iframe on click) on the ECG machine page, and also show it on the home page machines section and the packaging page (the old packaging page reused the same video).

## Design rule from Devan (important)
Cut taglines, eyebrow labels, helper text and secondary labels that aren't needed. No "Learn more" spam, no marketing filler, no invented slogans, no stat counters. Let layout, type and whitespace do the work. Industrial/medical, trustworthy, calm, not flashy. Navy/blue palette that suits their blue logo, lots of white, one accent at most. System font stack (no web font downloads).

## Tech
- Plain static HTML/CSS/JS only, no framework, no build step required to host: the deployable site is `site/` (upload as-is to any host / Cloudflare Pages). Shared header/footer may be generated by a tiny optional script (e.g. `src/build.py` that writes `site/**/index.html` from templates + `src/data.py`), but the committed `site/` output must be complete, static and working.
- One CSS file `site/assets/css/site.css`, one small JS `site/assets/js/site.js` (mobile nav toggle, video facade, form handling). No external requests on load (no CDNs, no Google Fonts, no analytics).
- Clean URLs as folders with index.html. Pages:
  - `/` Home: header (logo, nav: Electrodes, Production Machines, Contact; phone visible on desktop), hero on navy using the collage image, short real intro copy, 2 clear CTAs; electrode category grid (ECG, TENS, Tab, Adhesive Strips, Custom) with real images; key ECG features (from their Electrode Features list); machines section with photo + video; contact band; footer with full site map, address, phone, fax, email.
  - `/electrodes/` overview (their electrodes.php copy) + category cards + PDF guide download.
  - `/electrodes/ecg/` intro, Features + Options lists (with cloth.jpg & 2000ZT-with_logo.jpg), jump links to every shape, responsive card grid of all 27 shapes (image, part no., "Solid Gel - Foam Monitoring Electrode", size in inches + mm, pouch/case, cloth variant, TL225 note + its with-wire image), footnote, PDF link, anchors `#1000ZT` etc.
  - `/electrodes/tens/` grouped "Tin Conductive Element" and "Black Carbon Conductive Element" cards, plus the two PDF-only parts in a small table; "If you do not see a size or shape that you need, please contact us."
  - `/electrodes/tab/` TAB card (10 per card, 1.375 x .875 (35mm x 22mm), 100 electrodes per pouch, 1,000 per box / 4,000 per case) + Grounding Pads GP96 from the guide.
  - `/electrodes/adhesive-strips/` 5FS and 5CS cards with copy.
  - `/electrodes/custom/` custom electrodes copy + custom_electrodes.jpg + CTA to contact.
  - `/production-machines/` overview copy + cards to ECG machine and Packaging systems + inquiry CTA.
  - `/production-machines/ecg-electrode-machine/` copy, ECGMachine-Front1.jpg, spec callouts drawn only from their copy (e.g. 4.46875" standard material width, 2" max electrode width, single operator), video.
  - `/production-machines/packaging-systems/` copy (12 ft x 5 ft footprint, 8.25" poly/foil, pouches up to 11" long, dual pouch option, thermal transfer printer option), Packager.jpg, pouches.jpg, video.
  - `/machine-inquiry/` the full Machine Information Request form, with all their questions (see crawl text; required: Name, Company Name, E-Mail; gel type checkboxes Solid Gel/Wet Gel/Both; pre-printed pouch Yes/No; print on pouch Yes/No; B&W/Color/Both; special requests textarea; how did you find us). Group into logical fieldsets.
  - `/contact/` address, phone (tel: link), fax, email (mailto), contact form (Name*, Company Name*, E-Mail*, Phone, Questions & Comments*, How did you find out about Taylor Industries?), link to machine inquiry.
  - `/links/` their two links (Select Engineering www.selectengineering.com, R&D Medical www.rdmedicalproducts.com).
  - `404.html`.
- Forms: real `<form>` with proper labels, required attrs, autocomplete, and a JS submit handler that composes a `mailto:sales@taylor-ind.com` with subject + all answers in the body (static hosting fallback). Add a short HTML comment where a real endpoint would go. Show an inline status after submit. No placeholder text that repeats the label.
- `site/_redirects` (Cloudflare Pages format) mapping every old URL to the new one with 301s: /index.php, /electrodes.php, /electrodes/ecg_electrodes.php, /electrodes/tens_electrodes.php, /electrodes/tab_electrodes.php, /electrodes/adhesive_strips.php, /electrodes/custom_electrodes.php, /production/index.php, /production/ecg_machine.php, /production/packagers.php, /information/index.php, /contact_info.php, /site_map.php (-> /), /links.php, /Electrode_Reference_Guide.pdf (-> /assets/Electrode_Reference_Guide.pdf).
- `site/_headers` with sensible caching for /assets/* and basic security headers. `site/robots.txt`, `site/sitemap.xml`. Add `<meta name="robots" content="noindex">` to every page (this is a preview build; note in README to remove).
- Per-page `<title>` and meta description based on their own wording; Open Graph tags; JSON-LD Organization with only the real address/phone/fax/email.
- Accessibility: semantic landmarks, skip link, one h1 per page, visible focus, color contrast AA, alt text on every content image (decorative = alt=""), `aria-current` in nav, mobile menu button with aria-expanded, forms fully labelled, reduced-motion respected, tap targets >= 44px on mobile.
- Performance: width/height on every img, lazy-load below the fold, hero image eager + fetchpriority high, CSS < ~25KB, JS < ~5KB, no layout shift.
- Responsive: must look great at 1440px and 390px (and fine at 320, 768, 1024). No horizontal scroll on mobile.
